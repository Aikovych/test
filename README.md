# 📁 SOFT Furnishings — Структура сайту

## Поточна структура

```
soft-furnishings/
│
├── index.html          ← Головна сторінка (каталог)
├── style.css           ← Стилі головної
├── script.js           ← Скрипти головної
│
└── products/           ← Усі товари тут
    │
    └── plain/          ← Диван ПЛЕЙН
        ├── index.html  ← Сторінка товару
        ├── p1.jpeg
        ├── p2.jpeg
        ...
        └── p14.jpeg
```

---

## ➕ Як додати новий товар

### Крок 1 — Надішліть мені:
- Фото товару (скільки є — всі)
- Назву товару
- Ціну
- Характеристики (розмір, тканина, механізм тощо)

### Крок 2 — Я створю:
```
products/
└── назва-товару/       ← нова папка
    ├── index.html      ← сторінка товару
    ├── p1.jpeg
    ├── p2.jpeg
    └── ...
```

### Крок 3 — Картку "Незабаром" в index.html замінено на реальний товар
