# SOFT Furnishings — Структура сайту

## Поточна структура

```
soft-furnishings/
│
├── index.html              ← Головна сторінка (каталог)
├── style.css               ← Стилі головної
├── script.js               ← Скрипти головної
├── README.md               ← Цей файл
│
├── images/                 ← Прев'юшки для карток каталогу (1 фото / товар)
│   ├── plain.jpeg          ← Диван Плейн
│   ├── назва2.jpeg         ← Наступний товар
│   └── ...
│
└── products/               ← Сторінки товарів
    └── plain/              ← Диван ПЛЕЙН
        ├── index.html      ← Сторінка товару
        ├── p1.jpeg
        ├── p2.jpeg
        └── ... p14.jpeg
```

---

## ➕ Як додати новий товар — покроково

### Крок 1 — Надішліть мені
- Всі фото товару
- Назву товару
- Ціну
- Характеристики (розмір, тканина, механізм тощо)

### Крок 2 — Я створю файли
```
images/
└── назва.jpeg              ← найкраще фото для картки каталогу

products/
└── назва/
    ├── index.html          ← сторінка товару
    ├── p1.jpeg
    ├── p2.jpeg
    └── ...
```

### Крок 3 — Завантажте на GitHub
1. `images/назва.jpeg` → папка `images/` на GitHub
2. `products/назва/` → папка `products/` на GitHub (з усіма фото)
3. Оновлений `index.html` → замінити в корені

### Крок 4 — Готово
Картка «Незабаром» в каталозі автоматично стане реальним товаром

## 🔗 Правила посилань

| Звідки            | Куди               | Шлях                    |
|-------------------|--------------------|-------------------------|
| index.html        | Картка товару      | `products/plain/`       |
| index.html        | Фото картки        | `images/plain.jpeg`     |
| products/plain/   | Назад на головну   | `../../index.html`      |
| products/plain/   | Фото товару        | `p1.jpeg` (та сама папка)|
